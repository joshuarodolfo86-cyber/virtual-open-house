# VR Campus Open House - Sprint Plan

## User Stories

1. **Incoming Student**: As an incoming senior high student, I want to click on campus buildings so that I can learn about courses offered.
   - *Acceptance Criterion 1*: Clicking a building opens an info panel with details.
   - *Acceptance Criterion 2*: Clicking the close button hides the info panel.
2. **Parent**: As a parent, I want to teleport around the campus so that I can easily view facilities without complex controls.
   - *Acceptance Criterion 1*: Clicking ground markers teleports the camera view.
   - *Acceptance Criterion 2*: The scene functions smoothly on mobile screen viewports.
3. **Admissions Office**: As an admissions officer, I want to view visit analytics so that I can see which campus spots are most popular.
   - *Acceptance Criterion 1*: `/api/visits` logs every opened hotspot.
   - *Acceptance Criterion 2*: `/admin` displays real-time counts and summaries.
